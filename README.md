# 🚀 ITI Journey Portfolio — Ahmed Issam Ramadan

An interactive, high-fidelity storytelling landing page documenting my academic and professional journey in Digital Marketing and Graphic Design at the Information Technology Institute (ITI) Alexandria.

## 🏛️ Project Showcase

This portfolio showcases actual visual campaigns and strategic plans completed during the ITI track:

1. **Grand Egyptian Museum (GEM) Campaign ("Chaos"):**
   - Immersive dark-gold theme celebrating Pharaonic heritage with contemporary luxury aesthetics.
   - Designs include: Hologram Institute of Tutankhamun, Children's Interactive Museum, Khufu Solar Boat Museum, and Sunken Cities Exhibition.
2. **Athir (AIR) Content Strategy:**
   - Detailed target personas, multi-channel copywriting models (FAB, PAS, BAB), and video hooks.
3. **Strategic Marketing Frameworks:**
   - Launch strategy for a B2C Turnkey Interior Finishing firm (Group 1 project).
   - Competitor mapping, SWOT, PESTEL, and 7Ps analysis.
4. **Technical SEO Auditing:**
   - Mobile PageSpeed LCP fixes, keyword mapping, and competitor benchmarking.

---

## 💻 Tech Stack & Design System

- **Languages:** Semantic HTML5, Vanilla CSS3 (Custom variables, responsive grid), Modern JavaScript.
- **Scroll Animations:** Native CSS Scroll-Driven Animations (`view-timeline`) with an `IntersectionObserver` JavaScript fallback for older web engines.
- **UI Paradigm:** Futuristic Egyptian glassmorphic layouts (`backdrop-filter: blur(20px)`), deep space dark styling (`#06080d`), and neon gold typography glows.
- **Fonts:** Outfit (headings) and Inter (body) from Google Fonts.

## ⚙️ Running Locally

No compiler or build step is necessary. Clone the repository and run it directly in your browser:

```bash
git clone https://github.com/ahmedissamramadan/iti-journey-portfolio.git
cd iti-journey-portfolio
open index.html
```
